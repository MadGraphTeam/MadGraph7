# TIRust installation qualification

The MG CLI installed the final release with local source overrides, in offline Cargo mode using the populated cache. `cli.log` records successful publication and atomic configuration saving; `install.log` contains the installed Fortran smoke test. The smoke checks DP, binary128 input preservation, separate UV/IR poles, genuine poles-only evaluation and cache behavior. The 63 mocked compiler/lifecycle/notice/control tests in `unit-tests.log` also cover rollback and configuration-write failure.

`check-installation.json` records the observed configuration, native artifact hashes, availability, runtime SONAME/dependencies and exported-symbol audit. The archive, module and shared library themselves are not included. The original dependency notice archive and its provenance are included byte for byte.

The actual build applied patch `53b559ade233201659a1f9678188b4c761b9cc587267067bd354e7769ac62d9a`. The qualified source patch is `80ef17b367511419e734f760edca4593f15a324996c4830b815c03cf884cbab5`; `test-only-amendment.json` and `.diff` show that it changes three test-configuration lines only. The eight patched production files, six bridge/interface files and eight scalar-kernel source files were checked against the build stage before cleanup; their exact digests are in `production-source-identity.json`. The build is not described as having used the later test-only patch.

All commands ran from the MadGraph repository. The installer invocation was `CARGO_NET_OFFLINE=true python bin/madgraph .tirust-build/install-tirust.mg5` after sourcing `tools/tirust_env.sh`; `install-command.mg5` retains its exact command input. `toolchain.json` records the local toolchain. Absolute paths in Cargo metadata describe the original source/build locations; temporary stages were removed after successful publication.

The subsequent Python transaction audit is recorded in `configuration-transaction-audit.json` and `configuration-transaction-tests.log` (66 passing tests). It extends configuration-save failure rollback to the published installation and aliases. The native installation logs and original `source_sha256` capture above remain historical; `index.json` lists the later validated Python source hashes separately under `post_install_changes`. No native library, published configuration, or generated numerical source changed, and no native rebuild was performed for this correction.

The subsequent genuine no-override network installation is recorded in `clean-download/index.json`. It starts with empty task-specific Cargo and native dependency caches, builds downloaded pinned sources, and passes the actual serialized DP/QP/poles smoke and isolated configuration publication. Its copied source snapshot predates the later split-workspace bridge optimization; those later changes require their separate qualification. The original production artifacts remain unchanged.

The current split-workspace bridge also has an actual committed-source CLI publication in `current-source/index.json`. That run snapshots Git revision `606603e720`, reuses normal Cargo caches, downloads pinned dependencies without local overrides, and passes the real native smoke before isolated publication. Its native artifact hashes are recorded separately from earlier packages.
