Original warm scalar-only benchmark command, whose CSV is copied unchanged:

CARGO_TARGET_DIR="$TIRUST_MG_ROOT/.tirust-build/scalar-poles/target" CARGO_BUILD_BUILD_DIR="$TIRUST_MG_ROOT/.tirust-build/scalar-poles/build" cargo run --offline --manifest-path .tirust-build/scalar-poles/bootstrap/Cargo.toml --example benchmark_poles -- 20000 > .tirust-build/scalar-poles/benchmark-dev-opt2.csv

The temporary bootstrap Cargo.toml is reproduced in generation-provenance.txt.
It sets [profile.dev] opt-level=2; debug information remains enabled.
The CSV is neither a release benchmark nor an end-to-end MadLoop benchmark.
It is one warm dev-opt2 benchmark invocation, with 20000 repeated evaluations
per internal timing batch and the median of 7 such batches reported. It has
no confidence interval and is illustrative, nonacceptance evidence. These
data do not justify promoting any evaluation mode.
Massless C0 and D0 are slower in these measurements; the provenance file gives
the absolute differences and must accompany the CSV when it is reported.
