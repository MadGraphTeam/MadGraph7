# Final lightweight native-DP observations

Eight selected processes, Ninja6/NinjaRS8, exactly 100 shared points each.
Born cases use full sums; loop-induced cases use the preregistered all-minus
helicity. The empirical fraction resolution is 1%, and a zero count has a
one-sided 95% upper bound of approximately 2.95%. No heavy full100 extension or
runtime acceptance claim is part of this capsule.

Original JSON/raw bytes and their private paths are preserved. The finite
inventory maps each original file to an exact copy. Large repetitive guard
logs are gzip mirrors with their original uncompressed hashes; standard gzip
decompression recovers the original bytes. No executable, object, module,
library or generated build tree is included.

This is an observations/audit archive. Full source/runtime qualification used
the retained private compiled targets; a fresh checkout must rebuild and rerun
the documented process commands to repeat that physical qualification. The
tracked DP71 software capsule and final report contain the method and recipe.
The numerical observations and independent arithmetic audit can be inspected
without claiming a fresh native-runtime validation.

Hardware IEEE flags remain separate diagnostics. NRS8 has IEEE-invalid set on all 300 observations of qcd2/ew2/qcd3/ew3/ggHH, with finite coefficients/native success and zero common or algorithmic FPE. Matching plain-prefix flags establish that the recorder did not introduce them. This counts observations with a sticky flag, not invalid operations.
