# Committed loop-induced export-card qualification

This software checkpoint corrects a benchmark reader assumption. MadLoop's
committed loop-induced exporter applies three canonical defaults to its origin
card. The reader derives that exact policy from the declared generation revision
instead of requiring an unchanged base template. Born origins remain exact
template matches. Any extra origin setting or unknown exporter assignment is
rejected. Private Ninja6/NinjaRS8 cards retain the strict stability settings and
full pole computation; all numerical code, libraries and point streams are
unchanged.

The exact source/test snapshots passed 71 software controls, including the nine
new policy controls. The source review and read-only investigation of eight
origin cards and 32 private cards are retained byte for byte. No new physical
evaluation or compilation was performed. This capsule does not certify the
final eight-case numerical result.

Reproduce software controls from a matching repository checkout with
`python -m unittest tests.unit_tests.loop.test_ninjars_dp_stability -v`. The two
source copies are provenance snapshots; place them at their original paths when
reproducing an older checkout. Live private origin/build paths in the receipts
are historical bindings, so this is not a portable full physics bundle. The
earlier DP62 checkpoint and failed first assembly remain preserved separately.
