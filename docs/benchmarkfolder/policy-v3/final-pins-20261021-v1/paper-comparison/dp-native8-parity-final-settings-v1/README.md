# Native8 qcd1 recorder parity evidence capsule

This capsule preserves the completed, root-authorized native-DP recorder parity control for `u u~ > z [virt=QCD]`: selector8, 100 fixed points, forward/reverse/z90 transformations and two row orders. Scope is mechanical observer nonperturbation under the declared strict cards (`MLStabThres=1e-9`, `COLLIERRequiredAccuracy=1e-12`, forced DP). CPU12 and all four thread settings of 1 are historical run settings.

The exact independent audit in [audit/qcd1-native8-recorder-parity-independent-audit-v1.json](audit/qcd1-native8-recorder-parity-independent-audit-v1.json), SHA256 `6b73215bf08cc725233e7a6d50a670356df534a681b38bf5b97c0b882809d7b7`, reports 2,400 physical coefficients and 600 internal accuracy values bit-exact, 300 observation keys, 448 native DP status0 returns per variant, zero compensated/MP entries, 452 identical guard events, and seven owned child groups reaped with exit0 and absent. No physical zero coefficient was sampled. These are preserved audit findings; capsule preparation performs byte copying and hashing only.

`originals/` contains the exact raw streams, full result JSON including compiled-source/runtime manifests, guard streams, immutable runner/guard/frozen b0fa module, source/control receipts, compile/execute receipts and stdout/stderr, process ledger, launch observation, runtime handoff, complete/parity receipts and static validation. Empty logs and streams are retained. The copied private `originals/README.md` and `review-request.json` describe the earlier held prelaunch review state; later launch, completion and handoff receipts record the authorized run. Preexisting normalized build/execution metadata is retained as historical metadata, without a new qualification claim.

`originals/synthetic-static-fixtures/` contains eight synthetic parser fixtures, including synthetic native status1/2 and invalid guard inputs. They are software controls, not physical numerical results. `static_checks.py` is a source snapshot; capsule assembly did not execute it.

`bindings/` preserves the public cohort, original compiled-source anchor, fixed points, public Fortran driver and ABI header as exact source/control snapshots. Full generated-source/runtime closure and portable full qualification are not asserted. Downstream private qualifier artifacts are outside this capsule; the paper owner maintains the current reader and separate pilot manifest.

This capsule supports no physical accuracy claim, normal rescue or stability acceptance claim, timing/performance claim, full process campaign claim, or full scientific comparison. With no sampled zero coefficient, signed-zero preservation is not inferred from the physical rows. Preparation ran no producer, static-check script, qualifier, build, compiler, Cargo or numerical engine.
