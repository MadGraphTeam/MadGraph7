# Final dependency install and export qualification

This is a new campaign; historical ABI3 records remain unchanged. Preparation does not qualify an installation.

The primary installation will run actual `bin/madgraph` command cards against a committed source archive using the final locked Git dependencies, without local source overrides. Cargo cache and release target may be reused from the independently tested final release; the installer will still execute its normal locked release command and compile/run the installed Fortran native-DP, compensated-DP and genuine binary128 rescue smoke. The installation and all temporary work remain private until root publishes a validated runtime.

The archived CLI will generate standalone Fortran and full FKS/NLO `u u~ > z [QCD]` outputs with internal dependencies. Both outputs will be moved to new paths, copied archives/interfaces/configuration will be checked as regular files, and the private install will be hidden before evaluation. Standalone DP/QP/stability results will be compared with the retained CutTools reference and return integers 110/120/218 checked. Full NLO compilation must pass all twenty pole points and its soft/collinear test with NinjaRS selected. Dynamic symbol inspection must resolve the GNU binary128 helpers.

Fresh archived-source unit checks cover installer failure/retry/publication rollback, combined local-source overrides and source isolation, unavailable-only-8 errors, capability checks and statistics readers. They are software checks; actual runtime validation is reported separately.

Execution prerequisites are a committed/frozen numerical and generator revision, installer-final exact release inventory and final dependency lock, and numerical-final explicit release of the shared MP slot. No build or numerical evaluation had run when this plan was prepared. Retained execution records give the actual current result.

All commands, cards, source hashes, installed metadata and logs will be retained and sealed after real completion. Installation/export results are independent of the eight-process scientific and performance gates.
