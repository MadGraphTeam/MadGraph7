# Pure continuation and aggregate summary policy

This source-only helper creates no numerical observations and reads no active output. It is prepared for the immutable supervisor5 source index `5eded3d276bea030e9b8cce598f6422f10a789dc1eaa9ff6588275c2e594b931`. The source proposal remains `physical-stress-current-source-proposal-1`, index `5478869fa719db000df7df825202f3ae827080d1f00b43f38bad1506f5ab54ac`. The original terminal helper, SHA256 `619911189cc567691dc0ddddc4b7903dfee5b6385026ced5857284dcc86cd7ed`, is unchanged. This directory is not itself a sealed portable proof; its owner supplies capture, verification and an explicit source index separately.

`analyzer(worker_bytes, comparator_bytes)` accepts only the original worker SHA256 `71a460579b2cabe8a1485fa0eed406e98988ec019b6c195bd78af55eedf99d57` and comparator SHA256 `bc405b44d8d794cc4396ef3da3d48af238ac4dfb619c58901d7bab910a7e1370`. It extracts only their pure parser/status definitions and comparison function through Python ASTs. No compiler, loader, subprocess or worker is imported or launched. All remaining APIs accept ordinary Python data and do not access the filesystem.

`derive(plan, records, stage, accounting, aborted, protocol)` accepts the complete original plan and derives exactly `plan['requests'][4:]`: two remaining threshold lanes, then six lanes in each of the other three cases. It checks the original 24 unique request identities, four ordered cases, baseline/current lane order, exact 20-request accounting and terminal orchestration. The first four requests cannot be supplied again. The authenticated binder supplies each record's independently computed runtime verdict and binding errors; saved success booleans cannot replace verification.

The result has exactly 20 request rows and requested-lane coverage `2,6,6,6`. Complete eligible subsets may agree, but its `six_lane_all_cases_agree` is always false: it is not a full 24-request campaign. It retains observed warmup calls, partial/final coefficient and accuracy tokens, unchecked status120, W03 lines, nonfinite strings, native/controller/time-out/runtime failures, completion counts and unexecuted states. Valid failed evidence remains a valid summary. Nonfinite tokens are strings rather than nonfinite JSON numbers. An outer timeout cannot retain an inner success as a qualified stream. Per-row `failure_flags` are diagnostic observations, not substitutes for the retained failures or integrity checks.

`aggregate(original_verified_summary, continuation_summary, protocol)` requires both portable proofs to have been independently authenticated by their binders, including the continuation's exact admitted ancestor and all source/native/card/point/runtime identities, full raw parser results, final guards and owned cleanup. It does not authenticate capsules or establish those identities itself. The first input is the complete original 24-row summary with exactly four host-checked prefix requests, request5 deferred before launch, and 19 not started. The second input is the exact 20-row suffix derived above. It rejects overlap, omission, reordered identities and replacing an original suffix that already contains observations.

For every accepted stream, aggregation reconstructs comparator rows directly from authenticated `final_trace` coefficient/accuracy strings. It uses the frozen status validator, requires finite values, nonnegative accuracy at most `1e-6`, original backend/precision aliases, complete ordered point/order sequences and matching precision counts. The owning binders have already checked actual dimensions and status histograms using the frozen full parser. Aggregation invents no timing, dimension, histogram or numerical input. It then recomputes all eligible pair comparisons with the unchanged `3e-6` criterion and separate `1e-8` target. Mismatched split-order sequences are rejected by the frozen comparator.

The original six threshold-prefix comparisons are recalculated and must equal the original saved comparisons. They are returned as `inherited_comparisons`; their failing subset is also returned unchanged. This preserves all five original threshold disagreements in the actual admitted prefix rather than discarding them. With 24 checked lanes, there are 60 pair comparisons; full agreement requires all four six-lane cases to agree and the continuation terminal stage to have passed. A failed final stage leaves observed per-request consistency visible while keeping overall agreement false. Neither cross-reducer agreement nor integrity verification establishes independent physical truth, a repaired-geometry EW finite-term oracle, high-rank coverage or performance acceptance.

Both summaries expose `missing_or_unqualified_request_ids`, `not_completed_orchestration_request_ids` and `unexecuted_request_ids`. Observed raw counts and true orchestration completions remain distinct from host-checked qualification. The aggregate preserves the exact original four rows and all 20 continuation rows without editing either input.

The mocked tests exercise suffix admission, complete/incomplete accounting, timeout and runtime failures, status120 plus W03, nonfinite tokens, QP aliases, forged booleans/tokens/comparisons, two original split orders, duplicate requests, preserving five disagreements, and refusing full agreement after a failed post-stage guard. They are protocol tests, not scientific results. Run from the repository root:

