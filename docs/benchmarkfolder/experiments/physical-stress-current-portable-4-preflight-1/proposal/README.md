## Isolation and fresh source preparation

A byte-bound copy of the current generation could establish current generator provenance. Reusing its numerical objects is less defensible here: the original closed compilation records do not individually journal those objects, and active filters/resources are mutable. The agreed route therefore regenerates all eight exports with the actual MG CLI in two new disposable source clones, then fully rebuilds MODEL, DHELAS and process objects. It never reads/copies active worker cards, filters, FIFOs or raw files, and never invokes `make` or MG against a protected main export.

New work namespace: `.tirust-build/physical-stress-current-1/`. New evidence namespace: `docs/benchmarkfolder/experiments/physical-stress-current-qualification-1/`. Both must be absent before admission. Source clones `mg-candidate` and `mg-baseline` are materialized from the exact commits, with the candidate's complete registered source inventory checked before/after. Copy the pinned EW model into the new `models/` directory and check every manifest model-tree hash; built-in loop_sm comes from each exact source clone. Only installed external numerical dependencies may be shared read-only, after exact hash checks. All dependency compilation, if unexpectedly requested by generation, must target private source-clone copies; it must never write HEPTools or protected libraries. Preserve baseline model/source differences as provenance, and require the same physical card bytes.

`commands/` contains four original current CLI receipts and eight derived CLI scripts. The only script changes are private output/model paths and omission of unsupported `set tirust` for baseline. Every candidate script retains all five installed backend paths; each baseline script retains the historically supported dependencies. CLI environment has `PYTHONHASHSEED=0`, no bytecode, isolated XDG/cache/config paths and the pinned toolchain. `PWD` must equal each child cwd because legacy IREGI makefiles consume it. No configuration is persisted to the shared checkout. Source materialization/build records must bind compiler, environment, every generated source, all MODEL/DHELAS/process objects, archive inputs and link outputs before/after, using the successful lifecycle successor2 linker-script prebinding helper.

After CLI export, replace only the private physical card with the exact retained card before building. Render `protocol/stress-worker.f` with the newly generated prefix/dimensions. `driver-stdout.patch` removes the ordinary benchmark's `OPEN(6,FILE='/dev/null',...)`; it changes no floating-point operation, warmup sequence, phase-space repair, scale update, status gate, stability check or rescue policy. All other generated scientific source must match its fresh CLI output. Full object rebuilding includes this untimed diagnostic driver. The `--masses` execution is a separately admitted native preflight, never silently part of compile-only admission.

Actual proposed CLI argv/cwd and all build argv/cwd are enumerated per process/source in `proposal.json`. For example, the candidate EW CLI runs `taskset -c 12-15 <pinned-python> -B ./bin/mg5_aMC <absolute-proposal>/commands/candidate-ew_n3_epem_ttxa.mg5` from the new candidate clone. Each build uses `taskset -c 12-15 make --always-make -j4` separately in Source/MODEL and Source/DHELAS, then the same command with target `check` in the generated subprocess directory. No `make` command runs during a numerical lane.

## Native protocol and bounds

The implementation should adapt the frozen `protocol/` Python worker/cleanup helpers in the private namespace, without modifying their production versions. It needs a default dry-run and explicit coordinator-admitted stages; this proposal does not yet contain an executing supervisor. Use one owned-process supervisor per admitted stage, preserving exact launch argv, PID/start identities, signals, logs and bounded descendant cleanup. Mechanical preparation failure stops the stage; no automatic retries. Numerical rejection is an outcome and does not suppress later independent lanes. Provenance, cleanup or unexpected-library failures stop further launches.

Each backend gets a fresh private worker tree copied from its newly compiled private master export. Cards, resources, learned filters, FIFO and raw outputs are private per lane. Internal relative links must resolve within that worker or its own immutable private build, never a protected main export. Before/after each lane, check executable, scientific sources, physical card, selected points, static/native dependencies and resolved reader paths. Native preflight must use the binary's actual ELF PT_INTERP `--list`, rather than generic `ldd`. Record actual process maps and compare the exact bound ELF closure; classify non-ELF read-only data separately. A short-lived failed process with no map capture remains an observed failure, never a qualified numerical success.

Native commands are explicitly enumerated in `proposal.json`, e.g. `taskset -c 12 ./check <exact-selected.dat> <private-worker-protocol.fifo>` from that lane's generated subprocess. The controller waits for the original READY protocol, sends exactly `RUN 1 1`, captures the complete two-point traversal, then requests normal shutdown. Existing warmup alternation, bootstrap call, maximum warmup count and `FORCE_STABILITY_CHECK(.TRUE.)` remain unchanged. A stress refusal during warmup is retained as a warmup failure with exact call/point/status rows; it is not bypassed to obtain a later coefficient.

## Classification, evidence and independent truth

Retain all24 request records, including not-started, provenance failure, initialization failure, timeout, host rejection, nonfinite output and incomplete amplitude. Preserve exact stdout/stderr, W03 and other native diagnostics, FIFO messages, dimensions, every warmup row, final coefficients/status/accuracy, maps and bindings. Do not drop a warning because exit0 or status120 is present. Any unlocated omitted-contribution warning makes the stream incomplete; point-local attribution may narrow its scope only with explicit evidence. Primary qualification requires complete unique rows for both points and every declared split order, finite Born/finite/single/double/accuracy, checked H2/H3 status for the requested backend, steady T1/T2, nonnegative accuracy≤1e−6, no omissions, and intact provenance. H1—including120—is unchecked and cannot pass. Unknown/backend-alias statuses fail explicitly.

Report the exact existing3e−6 symmetric MadLoop regression result,1e−8 target result, and raw relative/absolute errors for each coefficient separately. Comparison must not hide small poles behind finite-term allowances. Accepted reducers disagreeing beyond a gate are accuracy failures, not resolved by voting. Rejected or incomplete streams retain raw diagnostic numbers but do not enter successful comparisons. Baseline/current CutTools are separately reported source controls.

Known historical limitations are context only: the soft/collinear point has common nonfinite Born; QCD pair-threshold DP poles previously needed separate QP adjudication; a later unchecked small-Gram result did not replace its initial checked timeout; EW's accepted Ninja result violated the independent pole relation. The new run must discover its own outcomes. There is no inherited current success.

Its absolute poles have a DP-Born/QP-geometry normalization limitation, and no independent finite-term oracle is available.
