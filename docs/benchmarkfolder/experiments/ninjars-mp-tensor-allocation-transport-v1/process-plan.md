This is the final proposed isolated performance comparison for the allocation
patch. No process build, evaluation or timing starts from this document alone.
Freeze exact archive/executable/source bindings and the controller before any
sample. Keep the completed callback-kernel series as separate evidence.

**Arms and inputs.** Compare corrected production9f13 transport with its original
tensor against that identical bridge plus the exact allocation tensor. Use
private static archives and private copies of the same final generated Fortran
processes from `generation-abi3-tensor-factor-v1`. Only the linked NinjaRS archive
may differ between arms; compiler settings, native-link metadata, module, every
generated source including the retained worker driver, cards and point bytes
must match. Record both complete numerical-library signatures; all other
archives must match. Do not install either experimental archive over HEPTools.

**Primary series.** QCD3 (`u u~ > z g g [virt=QCD]`), backend8, every100 original
fixed points and every answer order. Common core settings remainMLStab1e-9 and
Collier1e-12 with normal stability/rescue enabled. Exactly21 adjacent pairs:
original/allocation for even zero-based pair indices, reverse for odd indices.
One warmed100-point command per arm per pair. No point, rescue or slow sample is
excluded. A failed command remains a failed series, not a replacement sample.

**Regression series.** EW2 (`e+ e- > mu+ mu- [virt=QED]`), backend8, all100 fixed
points under the same policy, exactly7 adjacent pairs with the same alternating
order. This controls the unaffected ordinary-DP path. The full final eight-case

**Lifecycle and timing.** Reuse the frozen Fortran persistent-worker driver and
its controller parsing/parameter-card/status validators. Run only one NinjaRS

arm. This prevents simultaneous Symbolica owners. Initialization is outside the
reported elapsed interval but retained separately; full MadLoop numerator,
reduction, scalar integrals, stability checks and actual rescue remain inside.
The worker's identical tiny capture of the final traversal remains timed, and
serialization follows the timer. New process state for every arm is symmetric.

Require every physical coefficient, accuracy and return status to match exactly
between arms and across repetitions; also apply the frozen physical-tolerance
validator. Compare timed histograms and exact100-call counts. Keep dimensions,
raw values/timing/status files and diagnostics for every arm even on failure.
