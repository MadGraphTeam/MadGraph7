# Fixed stored-input replay

All 3,712 calls completed with status zero and finite outputs. Every native,
compensated, and full-QP reproduction control matched the captured output words
exactly: 464 semantic keys times three controls. All echoed input words matched
the independently constructed promotions and roundings, and the driver found no
input mutation. The original archive, module, and link metadata were rehashed
before and after execution. No production code or retry policy changed.

The independent raw parser and exact-dyadic audit in `independent/` also passed:
all eight input constructions, including zero signs, all reproduction controls,
and every retained per-loop contrast and reference norm agree. The package
verifier repeats both analyses without evaluating a library.

The fixed-geometry contrasts do not support replacing these genuine rescues with
a rounded-QP-coefficient DP attempt. The largest native-versus-generic difference
is 1.12600265e-9 in point 80, direction 2, loop 91; replacing the coefficients by
the rounded captured QP bundle leaves 1.12596445e-9. Both are about 1.10e-4 of that
loop's largest Laurent component. The corresponding generic-256 comparison of
original versus rounded-QP coefficient bundles changes at most 7.04162e-16
absolutely across all loops. Full-QP versus original DP geometry changes at most
2.15641e-13 in the generic lane.

These are stored-input observations, not a physical amplitude or stability gate.
The native and generic master-integral on-shell thresholds differ; the historical
generic transport loses negative-zero signs; and the QP coefficients were formed
from a changed external-point/parameter/Born bundle. Thus the dominant observed
discrepancy is on the reduction/provider side of this comparison, without a claim
that floating-point precision alone causes it. Rounded-QP coefficients can change
individual discrepancies in either direction. No mixed-precision retry is
implemented or recommended on this evidence.

`contrasts.json` retains every exact-dyadic per-loop comparison of all three
complex Laurent coefficients. The rational split is excluded from those metrics.
Huge relative changes between coefficient bundles occur near vanishing reference
loop outputs; the absolute maximum above is the useful scale. Formal unweighted
sums of the 116 loop outputs are also retained, explicitly without a claim that
they reconstruct MadLoop's fully normalized amplitude.

The original capture seal remains unchanged and excludes this namespace. The
offline analyzer's first attempt failed only because its sorting key passed
decimal strings directly to `Fraction`; the failed source, empty output, and
diagnosis remain retained. Correcting that conversion required no engine rerun.

Reproduction, from the repository root with the pinned development environment:

```sh
python -B docs/benchmarkfolder/experiments/ninjars-qp-numerator-dp-probe-v1/replay/verify.py
```

That command checks retained evidence only. Preparation and execution scripts are
single-use and refuse existing result files. Any new engine execution requires a
new namespace, the original captured runtime, and an explicitly coordinated MP
slot. Execution elapsed time is diagnostic and carries no performance claim.
