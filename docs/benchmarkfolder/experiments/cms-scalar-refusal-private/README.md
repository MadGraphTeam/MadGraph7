# CMS classifier source, build and mock milestone

All 17 compiler/linker commands passed. The actual AVH and checked CutTools
interfaces compiled; the two linked and executed tests used recording analytic
and coefficient stubs. The successful replay passed both exact-runtime loader
checks, the classifier mock and the caller mock. Protected source parents,
numerical binaries and expected outputs remained unchanged.

The classifier completed eight overloads in each of DP and genuine QP, including
nonzero-erasure refusal, native norm/permutation handling, original operands,
bounded events, nonfinite publication refusal and caller-buffer preservation.

variants, 182 primary cases, and 546 direct/adapter/reset mock reduction calls.

The original launcher failure is retained in full. It stopped before either
mock because exporting the target glibc path broke outer `taskset` with a
`GLIBC_PRIVATE` symbol error. The append-only replay selected target libraries
through the exact ELF interpreter's `--library-path`; neither numerical binary
nor fixture changed. Both failed and successful run records, raw loader/mock
streams, full caller journal, source indexes, preparation, tests and correction
diff are included. Earlier source-test drafts and their failures remain in the
unchanged nested build evidence.

This qualifies the stated mock assertions and compiled interfaces only. Actual
analytic scalar accuracy, physical amplitudes, full MadLoop host rescue,
hardware IEEE sticky flags/traps/rounding transparency and performance remain
unqualified. The tests assert finite/NaN predicates, storage bits and software
refusal latches; they do not assert hardware exception flags. Loader identities
are retained observations, not re-resolved by this portable verifier.

Run `python -B verify.py` from any working directory. The verifier checks exact
file coverage/hashes, source/native identities, the failure/replay chain,
process scopes and both frozen mock parsers without the original workspace,
Nix runtime, compiler or native execution. Native modules, objects, executables
and system runtimes are hash-only; no binary is bundled. Retained source recipes
keep their historical paths for provenance and are not relocated launch scripts.

`manifest.json` describes the evidence; `source-index.json` and `SHA256SUMS`
cover every bundled file. The entire directory is safe to copy as one unit into
tracked benchmark documentation. No production source or older evidence was
modified while packaging.
