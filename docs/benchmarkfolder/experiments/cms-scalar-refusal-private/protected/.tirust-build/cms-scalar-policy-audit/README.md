# CMS scalar classification: source-only proposal

The retained point20 defect belongs to CutTools1.9.3's vendored AVH OneLOop scalar classifier, not the TIRust `oneloopmaster` dependency. No source, installed library, setter, card, or native result was modified in this audit. It is independent of the proposed backend8/9 QP model-mass transport patch.

## Established mechanism

`vendor/CutTools/src/cts/cts_cuttools.f90:77–95` suppresses all scalar messages and calls the generic `olo_onshell(1d-6)` during initialization, including the QCDLoop configuration that uses AVH for tensor bubbles. `avh_olo.f90:35251–35259` forwards this setter to DP, QP and MP module states. It is process-global; no per-call policy argument exists in these overloads.

`avh_olo.f90:18248–18255` sets `nonzerothrs=.true.` unconditionally, including a zero argument. Therefore `olo_onshell(0)` does not restore automatic behavior. The public getter returns the numeric threshold only (`:18275`), not the absolute/default-mode flag; generic get/set cannot faithfully snapshot and restore both. The untouched default mode uses a precision-derived `neglig` value, scaled by a local maximum in the wrappers, but generally warns about near-zero inputs instead of clamping them. It is not an existing ready-to-use relative snapping policy. QP `neglig` also influences deeper analytic branches independently.

The actual real-invariant/complex-mass triangle overload is `c0rc` (`:21229`): `abs(p)` and complex mass magnitudes below the absolute cutoff become zero classification flags (`:21292`), as do selected invariant-minus-mass differences (`:21323`). Complex masses are retained as complex values; testing only a projected real mass would be wrong. The corresponding box `d0rc` starts at `:22414`; classification at `:22493` and differences at `:22546` are accompanied by soft-kinematic permutation logic. A check confined to external masses or the six box invariants would miss these difference comparisons. Other overloads and bubble/scaleless branches require the same policy.

`cts_loopfunctions.f90:428–451,489–516,549–588` reconstructs MP scalar invariants from CutTools' denominator shifts and calls the scalar kernels. The legacy `cts_cutroutines.f90:298–312` first promotes DP denominator inputs into MP. Thus a QP arithmetic epsilon alone does not bound inherited DP momentum/mass error. The frozen point20 intervention separated scalar misclassification from this distinct denominator transport defect: lowering the private scalar cutoff preserved all scalar inputs and removed the large error; feeding repaired QP momenta was additionally necessary to remove the remaining finite disagreement. The evidence is under `docs/benchmarkfolder/experiments/complex-mass/direct-qp/cuttools-adjudication/` and remains unchecked fixed-QP diagnostics.

Scalar APIs return Laurent arrays, not a structured unsupported/status result. For example a zero-input box writes a diagnostic and returns zero (`avh_olo.f90:22481–22486`). CutTools currently assigns `STABLE` from reconstruction tests (`cts_cutroutines.f90:323–325`), without a separate scalar-classification failure flag. A bounded refusal must therefore propagate a dedicated status through the scalar/CutTools caller and MadLoop rescue path; merely logging, returning zeros, or lowering the cutoff would be insufficient.

## Recommended staged design

1. Start with a private, additive scalar-classification observer/refusal entrypoint, leaving all legacy AVH/CutTools symbols and global settings unchanged. Report every proposed nonzero-to-zero classification, its input kind/precision, original value, local scale, exact criterion, subtopology and direction. Cover mass magnitudes and invariant-minus-mass tests as well as invariants. This can establish which changes require numerical uncertainty handling or graph-level on-shell identity. No observer or refusal implementation has been authorized by this note.
2. A general replacement should accept explicit per-call zero/onshell provenance and error bounds in the actual arithmetic/input precision, rather than infer physics from a magnitude threshold. Preserve every resolved nonzero physical transfer regardless of absolute unit scale. Certified massless or equal-mass shell identities may be snapped only when the residual fits a justified bound and the parameter/momentum representations agree. Composite, off-shell, unknown or inconsistent targets cannot acquire a shell identity merely because their residual is small.
3. Numerical bounds must account for both input uncertainty and operations: momentum differences, Minkowski sums with cancellation, squared real/complex model masses, and the selected direction. A scale such as the sum of absolute product terms is more informative than the final tiny invariant. Bounds may use operation-count rounding factors in the actual precision, but a universal `C*epsilon*max_scale` is not by itself an on-shell proof. Near-zero values that cannot be classified reliably should request higher precision from the existing host policy or return explicit unsupported/unstable status. DP-promoted inputs remain DP-limited even when subsequently evaluated in binary128.
4. The least invasive bounded-support alternative is to reject any *unqualified* nonzero value that the existing classifier would erase. This is conservative and may refuse otherwise valid on-shell rounding residues; it must be advertised as limited support, not as a complete numerical repair. It requires explicit scalar status propagation and invalidation of incomplete results, plus checked host rescue. Fixed positive CTModeRun diagnostics cannot establish that host behavior.
5. If later implemented, pass policy/precision/provenance explicitly or through a private context with documented lifecycle. Do not use the generic process-global setter around individual calls. Any scalar cache must separate policy, precision, full/poles family, primary/check direction and model/event generation; failed or ambiguous classifications cannot populate a successful result store. Reentrancy and worker/process isolation need qualification.

## Qualification needed before admission

Keep original and repaired transport axes separate. Cover DP and genuine QP, real and complex masses, exact zeros, tiny physical nonzeros, near-on-shell differences, threshold/soft/collinear limits, opposite orderings, scaleless poles, and model updates. Include power-of-two common rescalings of masses/momenta/scale and verify unchanged analytic classification with dimensionally correct Laurent rescaling. Test error bounds when Cartesian inputs are promoted DP versus repaired QP. Compare against independently checked reducers and higher precision, preserving every refusal. Test call-interleaving/global-state invariance and explicit host failure/rescue propagation. A lower private cutoff fixing one saved point is evidence of the defect, not a general cutoff recommendation; there is no performance claim here.
