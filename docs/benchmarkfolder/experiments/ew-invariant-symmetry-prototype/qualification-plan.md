The candidate inserts two blocks into the frozen generated EW n3 adapter, one DP and one QP. It preserves every existing reconstruction operation and all shared kinematic-builder/on-shell decisions. The strict native symmetry and finite-input checks remain unchanged. Diagonal values, already equal pairs, signed-zero bytes, masses, shifts, scale, mode and check-pass controls are untouched. This is an ABI input-canonicalization proposal, not a tolerance relaxation or new reduction method.
