## Proposed experiment and existing evidence

The controller reuses the already built checked diagnostic executable
`0181fba617011c58b36cc8d59bbc92d807f670f19f3d74ea64dc8539b11c8e28`
and all 25 numerical objects unchanged. The driver witness records the same
bootstrap, alternating two-point warmup and consecutive T1/T2 readiness
protocol. Readiness identifies finished initialization and is never physics
acceptance.

Four fresh guarded-library workers were proposed: checked masked/trapped
with `CTModeRun=-1`, `NRotations_QP=1`, and forced-QP masked/trapped with
`CTModeRun=4`, `NRotations_QP=0`. Each card is byte-identical to its corresponding
closed comparator. The physical inputs, genuine binary128 mass/numerator
path, backend9 selection, thresholds and other controls remain fixed.
Three deliberate invalid/divide-by-zero/overflow fault controls and one
runtime-loader listing were also proposed. Existing original/adaptive
comparators are reused as frozen text; they are not rerun.

The inherited process supervisor enforces the common nonblocking numerical
lock, CPU12 without reservation, 4GiB address space, 120 seconds per physical
worker, 10 seconds per fault/loader worker and one 600-second aggregate
deadline. Actual 15-library mappings, reaping, input closure and output closure
are required. There is one attempt and no automatic retry. No such attempt
has been created here.

## Qualification gates

The journal parser, named IEEE parser and checked-output qualifier remain
unchanged. Every physical outcome retains public code, accuracy bits,
DP/QP classification, QP call counts, complete/partial traversals, model
snapshot counts, raw outputs, software failure latches and hardware flags.
A DP-to-QP or QP-to-DP change is reported explicitly. Unmatched QP groups and
snapshots are coverage changes; the shared saved-input/Born comparison and
its full-comparability flag remain distinct.

Numerical agreement uses the existing `tools/tirust_benchmark.py`
`LoopMEComparator` criterion at `3e-6`, retaining its ordinary target `1e-8`.
All Born, finite, simple-pole and double-pole ANS columns are compared against
the closed successful c5de reference, separately for both new policies.
Masked versus trapped ANS results receive the same numerical comparison.
This gate does not require identical public status, accuracy words, precision
selection or number of calls. Strict bitwise status/output/raw-tensor
comparisons remain diagnostics, with matched and unmatched groups counted.
The original incomplete checked result remains a historical diagnostic;
it is not a numerical agreement reference.

Host stability acceptance comes from actual MadLoop checked returns219/323,
finite nonnegative independently returned accuracy below `1e-6`, complete
finite outputs and zero W03 omissions. The existing qualifier also verifies
the observed checked sequence when QP is used. A cleaner FPE state cannot
establish this gate. A valid all-DP checked result leaves auto QP coverage
false without failing numerical agreement or host acceptance.

QP path coverage is reported separately. Auto checked observations retain
actual `[4,5,4]` coverage where present. Forced-QP controls require unchecked
status120, exact accuracy sentinels `[-1,-1]`, one 200-group mode4 traversal
and one genuine-QP model snapshot per point. Every group must be served and
stable with backend9, check-pass false and caching enabled; tensors,
contractions and amplitudes must be finite and W03 count zero. Status120
never establishes independent host stability. These controls supply their
own QP coverage even when the auto path selects DP.

Trap completion requires a complete trapped worker with the named requested
halting policy and all three deliberate fault controls demonstrated.
Numerical agreement and host-acceptance measurements do not become failures
merely because a fault control is undemonstrated; the trap gate remains false.
Every published gate still requires complete transport and final immutable
input/runtime closure. A deadline or closure failure rescinds all qualified
gates while retaining provisional measurements and raw failure evidence.
The composite checked/trap field requires numerical agreement, actual host
acceptance and trap completion; auto QP use is reported separately. The
forced-QP composite uses numerical agreement, QP coverage and trap completion,
with host stability explicitly false.

Independent physical truth, per-call 256/512-bit provenance and performance
remain unqualified. This is the old private genuine-MP-mass diagnostic,
separate from `invariant-symmetry-1` and production. No installation prefix or
COLLIER code/cache behavior is changed.
