`0181fba617011c58b36cc8d59bbc92d807f670f19f3d74ea64dc8539b11c8e28`

## Qualification gates

The existing checked journal parser, named IEEE parser and checked-output
qualifier are reused unchanged. Checked acceptance requires independent
MadLoop checks, observed QP coverage, complete sums and zero W03 omissions.
The source journal identifies complete `[4,5,4]` traversals but does not
explicitly label the rotation or report each call's working precision.

The separate fixed-QP qualifier requires unchecked status120, exact accuracy
sentinels `[-1,-1]`, one 200-group mode4 traversal and one genuine-QP model
snapshot per point. Every group must be served and stable with backend9,
check-pass false and caching enabled; raw tensors, contracted results and
amplitudes must be finite. W03 diagnostics reject contribution completeness.
Status120 never establishes numerical stability.

Both policy workers must preserve physical inputs, Born values and outputs
exactly where required. The frozen c5de checked and fixed outputs must remain
exact; all previously served original checked results must also remain
exact. Named hardware observations and inherited software failure latches
stay separate from physical input comparisons. Both qualification gates
require successful trap controls, complete transport and final protected-input
closure; deadline or closure failure clears them.

Independent physical truth, per-call 256/512-bit provenance and performance
remain unqualified. This is the old private genuine-MP-mass diagnostic,
separate from `invariant-symmetry-1` and production. No installation prefix or
COLLIER code/cache behavior is changed.
