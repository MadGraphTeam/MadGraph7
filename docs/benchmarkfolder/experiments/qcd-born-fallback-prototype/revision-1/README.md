This folder contains a private generated-export prototype, separate from the frozen Born-cancellation proof. It is not a production change or a qualified numerical result. Compilation, execution and ordinary-path overhead measurement are held while the shared host is overloaded.

The wrapper first executes the original DP Born routine. Finite ordinary answers return unchanged. A nonfinite result triggers a same-input QP calculation using the already validated MP DHELAS kernels and exact promotions of DP model parameters. The cloned aggregation retains helicity, polarization, flavor, split-order and averaging rules; it shares the original integer/logical selection state, while preserving the DP beam-polarization COMMON layout.

An IEEE status snapshot precedes the original DP call. The wrapper never suppresses caller traps; an enabled trap retains its original abort behavior. Only the fallback restores entry state to discard exceptions from the failed DP attempt, then checks QP arithmetic and output conversion. Newly raised QP flags are merged with the caller's entry flags. Nonfinite QP output or invalid/divide-by-zero/overflow during rescue is an explicit failure.

The host hook replaces all Born split-order outputs before computing `REF`. A successful Born rescue forces the existing checked QP loop-rescue path for automatic stability mode. It does not promote an unchecked loop result. A failed QP Born bypasses loop evaluation through normal host cleanup, then forces rejected status H=4, T=2, U=0, accuracy=1 and nonfinite outputs. Successful ordinary DP calls retain their original coefficients and status path.

Before promotion this prototype needs source review, ordinary bit-for-bit comparison, caller-flag preservation, explicit enabled-trap tests, invalid-QP rejection, whole-amplitude checked rescue and pole normalization, and paired ordinary-path timing. The single IEEE snapshot and finite guard may matter for the tight n1 performance budget. Existing phase-space repair of the loop rescue remains the historical host behavior; this prototype does not silently repair the Born input.

`prepare.py` derives the files from the frozen QCD n3 generated export, asserts unique transformations and records source identities. It performs no compilation or native calls. Do not run it twice in the same evidence namespace. The production exporter is owned by another agent and is deliberately untouched.
