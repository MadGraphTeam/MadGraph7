## Observer record contract

The cross-language event interface is `event(tag, int64_words, size)` with `begin_point(point, phase)` and explicit control/flush outside numerical work. Log payloads represent bit patterns and integer control metadata, never recomputed floating point expressions. The source proposal's public log has a `DCO_PUBLIC 1` header followed by exactly `PUBLIC`, `INPUT`, `ANS`, `ACC`, `STATE`, and `HEALTH` per public call. The `PUBLIC` integers are sequence, point, phase, loop, status, input-word count, answer-word count, and accuracy-word count. For these processes the word counts are 21 (Fortran column-major `P(0:3,1:5)`, then `MU_R`), 8 (`ANS(0:3,0:1)`), and 2 (`ACC(0:1)`). Hex words have exactly 16 digits. `STATE` has 11 entry and 11 exit integers: invalid/divzero/overflow/underflow/inexact flags, the five corresponding halting modes, and rounding mode (`nearest=0`, `zero=1`, `up=2`, `down=3`). Unsupported rounding remains a qualification failure. `HEALTH` requires zero host faults, zero native faults, and zero flush status.

The native source proposal emits JSONL `flush_begin`, ordered `event` records, and matching `flush_end`, followed at shutdown by one empty flush and a distinct `close` trailer. Every event carries sequence, point, phase, native-call identity, raw C/MPFR state before/after, and tagged data. Per-hook FP-state equality and clean health are separate requirements from cross-arm public parity. A native error does not authorize reading undefined result buffers. A cache-hit record denotes reuse, not a fresh numerical evaluation. Native counters that aggregate work across precision lanes cannot be reported as pure-DP work. The public log also requires the final `CLOSE 100 100 0 0` record; every process must later have independent successful-exit evidence.

`analyze.py` is a source-only retained-text validator for the agreed public and native v1 schemas. Its CLI takes `--case`, `--original`, `--disabled`, and `--enabled` existing run directories and prints JSON without writing artifacts. Each directory must contain `cause-public.txt` and `warmup.dat`; the private disabled/enabled directories must also contain `cause-native.jsonl`. The parser requires 101 public calls, 102 native flushes, exact native/public tag joins, intact close records, clean health/drop counts, consecutive sequence/native IDs, and the registered default native policy. Every arm's complete `warmup.dat` must equal the pinned historical stream byte for byte. It compares all public input, answer, accuracy, status, entry-state, and exit-state fields across arms. Public files are capped at 2 MiB; native journals at 512 MiB with 1 MiB lines and the source's 200,000-event per-flush ceiling. Exceeding these bounds fails the attempt rather than triggering a retry.

After structural/parity validation, the analyzer reports concurrent observations such as native DP status failure, Fortran guard return, the host software rejection latch, pre/post-override stability estimates crossing the captured threshold, and the actual QP escalation branch. Raw threshold/estimate words are retained; their offline binary64 interpretation never enters the numerical prototype and is not formatted as a floating value in the report. A latch name does not establish an IEEE exception. Successful parsing sets `native_journal_validated=true`, while `runtime_provenance_validated` and `cause_attribution_qualified` remain false until a separately authorized runtime controller supplies that evidence. Neither helper nor analyzer has been executed or tested in this source-only turn.

It must preserve 64-bit words as integers or fixed-width hexadecimal text and never parse them as floating point.
