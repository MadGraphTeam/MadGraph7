This addition prepares a separate build stage for the frozen `b0b0af81…` observer proposal. The authorized `cause-1` attempt failed during cache copying, before any compiler, Cargo invocation, test, reducer, or amplitude. Its only child command applied the frozen upstream patch successfully. The first controller sources remain verbatim in `revision-1/`; its ignored work and failure manifest remain unchanged. An explicit reviewed `--build --expected-plan-sha SHA256` command is required to compile; it does not invoke the six-arm replay. No approval file is created or inferred.

The historical installer removed its temporary source tree. `native-inputs.json` therefore binds the available inputs for reconstruction: 463 pristine TIRust files, the exact 14-file pole-kernel source, the reviewed zero-fuzz patch, retained bridge source, and the installed resolved Cargo lock `c4f59f29…`. The current toolchain and environment are recorded as a new diagnostic environment; the unavailable full historical environment and old DSO byte reproduction are not claimed.

Cargo receives private copies of only the locked registry package sources, matching archives and sparse-index entries, and the exact locked Git checkout roots with their corresponding databases. The pinned TIRust manifest origin is also copied for offline resolution; the existing graph check still requires its private patched path replacement. Only copied checkout origins are redirected to the private databases. The unrelated GammaLoop checkout is excluded: the first attempt encountered a directory symlink there because it copied the whole shared cache. `cache-copy-preflight.py` checks the narrowed selection without invoking Cargo or compilers; its retained receipt records all 150 package roots covered and no selected symlinks or missing paths.

Fresh private target/build directories remain in use. The builder checks the 150 external package source trees, resolves exactly the installed locked dependency graph, and rechecks sources after compilation. This may rebuild all dependencies, including Symbolica and GMP. The proposal fixes CPU 11, one Cargo job, and a 1,800-second build deadline; it makes no short-build promise. Timeout or failure is retained and is not automatically retried. No shared Cargo target, production/reference source, installed archive/module/library, or numerical cache is written. GMP, Symbolica, XDG and temporary build write locations are private. The large failed work tree and its 54,669-file artifact inventory are retained only under `.tirust-build`; they are not repackaged into Git.

Each generated process uses its retained actual compiler/link commands and original numerical objects. The original arm recompiles only the instrumented public driver and links the common observation module plus the C no-op shim to installed `eb3d67fd…`. The observed arm additionally recompiles the instrumented common TIR, TIRust adapter, and loop-matrix routines. Observer-disabled and observer-enabled replay use the **same** observed executable and DSO. Numerical compiler flags and link object order are preserved; only declared private source/object paths, module paths, observer objects, DSO selection, and diagnostic link maps are added.

The C flag reader is a final-crate linker input, not a global Rust flag affecting dependencies. It never adds a host MPFR library. Completion requires local definitions of the flag reader, numerical MPFR entry, and flags TLS storage, together with their actual same-archive cross-reference origins, accepting an MPFR archive or Rust's bundled numerical archive. Every Fortran link `LOAD` input must match a prebound frozen dependency, copied object, declared new object/library, or compiler runtime input. These gates may refuse an unfamiliar linker format; refusal is not evidence of numerical failure.

The executable's actual `PT_INTERP --list` supplies each recorded runtime closure under the same fixed environment proposed for replay. The two historical `ldd` loader aliases are not treated as two loaded interpreters. All non-TIRust library hashes must match the frozen runtime; later actual process maps remain required. A build manifest at `WORK/build/build.json` records commands, logs, objects, source copies, link maps, runtime closure, and unchanged protected inputs. Compiler ownership/cleanup uses the separately hash-bound controller's `OwnedChild` implementation, keeping the leader unreaped until its group is cleaned up. Metadata errors cannot replace the original command failure.

Build success alone does not qualify cause attribution, pure-DP execution, observation neutrality, numerical accuracy, or performance. Those require the separately reviewed original/disabled/enabled replay and its retained parser/provenance checks. Current default options alone are in scope; a `Direct` route is not a pure-DP certificate and internal partial work is unobserved.
