# Physical parity and targeted benefit gate — source only

This proposal is unexecuted. It uses the closed current-source ordinary QCD
`u u~ > z g g [virt=QCD]` process, its exact numerical objects/cards and saved
100 points, with the unchanged `eb3d67fd…` TIRust shared library. The production
Fortran module and installed files remain unchanged. Exact original/candidate
MTIRUST sources come from the closed optional-decoder proposal and parser
qualification; only private explicit objects differ.

BUILD has300s all-in, with60s cleanup. It materializes isolated copies, removes
all HelFilter/LoopFilter files, and creates private parity and timing drivers.
It compiles only each private MTIRUST module and driver, reusing the frozen
model/DHELAS/numerical process objects. A separate wire-observer executable
links a recording C wrapper around `ml_tirust_evaluate_mp`; no Rust compilation
or new native library is permitted. Every link places private MTIRUST before
the process/static archive. Unique symbols, absence of archive MTIRUST
extraction, prebound actual linker LOADs, actual PT_INTERP/runtime providers and
the unchanged DSO hash are mandatory. Discovery/link queries occur only inside
BUILD. Original compiler/flags and all reused object identities are retained.

PARITY has600s all-in, with60s cleanup, and requires a separately reviewed
successful BUILD hash. Original/candidate/wire workers each begin fresh with
the identical full100 learning traversal and original automatic rescue policy.
Original/candidate call anchors1 and16, requiring DP219 and automatic-QP323,
then all100 saved points. Both split orders' Born/finite/poles, accuracy words,
statuses, and read-only IEEE pre/post flags/halting/rounding observations must
match exactly. The ordinary closed warmup/reference identity is retained.
No fixed-QP substitution, shortened learning or flag clearing is permitted.

The observer uses the original exact scientific module and the same parity
driver plus capture-enable/disable calls outside the observed amplitude calls.
Its raw native output records are recorded separately after successful native
QP reductions during the102 post-learning calls. The wrapper preserves every
argument/output byte/native status and never replaces a native result with an
I/O failure. A separate capture-health result must pass. Its complete numerical
and IEEE parity with the original is mandatory before the wire data are usable.
Offline analysis counts exact64-byte whole batches passing the candidate's
canonical spelling and mode/environment gate. It does not assume that every
real formatter result qualifies. Failed native statuses are retained explicitly.

TIMING has480s all-in, with60s cleanup, and requires separately reviewed BUILD
and successful PARITY hashes. It uses the original/candidate uninstrumented
timing executables, each freshly initialized with unchanged full100 learning.
The frozen cohorts are point1 (native DP) and point16 (automatic QP), separately.
Two retained calibrations per variant/anchor select one common fixed integer
loop count per anchor, targeting at least1s. A measured slower time is retained;
there is no timing retry or best-of selection. Seven pairs per anchor alternate
O,C / C,O starting with O,C; anchor1's seven pairs precede anchor16's seven.
All timed status counts and final coefficient/accuracy words are retained.
Coefficients/status must match the qualified anchor; accuracy words must match
between original/candidate with identical call history. Drift from the earlier
PARITY-anchor accuracy is separately retained as a diagnostic, without assuming
that legacy accuracy estimates are history-independent. Fortran SYSTEM_CLOCK surrounds only full amplitude calls;
IEEE queries and file output are outside timed intervals. Initialization is
reported separately.

These are targeted-anchor shared-host observations, not whole-process,
baseline-chain or local <=1.05 performance acceptance. A negative/zero benefit
is a valid reason to reject promotion. Full physical100-point traversal is an
accuracy gate, not a substituted timing cohort. Actual raw durations, accepted
DP/QP usage, cache/card/stability settings and host load remain visible. The
final precise performance campaign stays Hua-Sheng's local TODO.

All phases share the existing numerical mutex and nonexclusive CPU12, one
thread,16GiB address-space/512MiB file/zero-core limits and identity-checked
bounded cleanup. Every phase includes prechecks, clone work, execution,
postchecks and failure closure in its original cap. Source/pure tests invoke no
compiler, loader or native worker. A failure is retained and stops dependent
work; each native phase requires its own root review/admission.
