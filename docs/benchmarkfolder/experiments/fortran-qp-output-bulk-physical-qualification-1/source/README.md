# Optional QP decoder: physical parity and targeted timing proposal

This is a source-only, uncompiled proposal. The production Fortran module,
installed TIRust/oneloopmaster library, original process and earlier results
remain unchanged. `PLAN.md` defines the complete bounded protocol.

The fixed process is current-source QCD `u u~ > z g g`, with its195 frozen
sources,144 numerical objects/modules/archives, original cards and100 saved
physical points. Both exact MTIRUST modules are private explicit objects. The
candidate is the same bulk-decoder source qualified with the recording-provider
unit corpus; this proposal does not assume that unit parity proves physical
amplitude parity or a runtime gain.

Three independently admitted stages are available: BUILD300s, PARITY600s and
TIMING480s, each including60s cleanup, shared numerical mutex and nonexclusive
CPU12. BUILD compiles only the private adapter/driver and observer C shim; it
reuses the unchanged numerical process/model/DHELAS objects. Private MTIRUST
precedes every process object and archive, with unique-symbol/no-archive-module
extraction checks. The exact original15 runtime providers are explicitly joined
and rehashed before linking, followed by actual linker LOAD, actual PT_INTERP
listing and worker maps checks. GNU make receives a hash-pinned explicit Bash
path because the generated `/bin/bash` spelling is absent on this harness.
Compiler flags and injected compiler environment match the closed originals.

PARITY runs three fresh original/candidate/wire-observer workers. Each preserves
the entire original100-point learning sequence, then calls anchors1/16 and all
100 final points. Born/finite/poles and accuracy use exact public REAL8 words,
with actual backend/status and read-only IEEE observations. The anchors retain
native DP219 and automatic QP323. No fixed-QP replacement or IEEE setters are
used. The original-only observer forwards the real native C ABI unchanged and
captures actual raw64-byte output records and post-native rounding/halting
environment. Its numerical and IEEE parity must pass; I/O health is separate.
Offline eligibility counts describe the original native wire's potential
candidate path, not instrumented candidate branch counts.

TIMING is available only after separate successful BUILD/PARITY review. Its
original/candidate workers are uninstrumented and freshly learn all100 points.
Two calibration pairs use common loop counts, preserving identical call
history; seven timed pairs alternate order for each fixed anchor1 then16.
Coefficient/status words must match the qualified anchor. Accuracy words must
match between workers at identical histories; any drift from the earlier
PARITY-anchor accuracy is retained separately as a diagnostic. Raw durations,
all timed status counts, final words, initialization and host load are retained.

Timings are targeted-anchor shared-host observations. They do not qualify a
whole-process, starting-baseline-chain or local performance-acceptance claim.
Zero or negative benefit is retained and can justify rejecting promotion.
Candidate promotion remains false; Hua-Sheng's precise local campaign is still
separate. No native phase runs automatically or retries after a failure.

After root and independent source review, commands use an exact source seal:

```sh
python3 -B controller.py --preflight --phase build --source SOURCE_SHA256
python3 -B controller.py --execute --phase build --source SOURCE_SHA256
# After separate closed BUILD review:
python3 -B controller.py --execute --phase parity --source SOURCE_SHA256 --reviewed-build BUILD_TERMINAL_SHA256
# After separate closed PARITY review:
python3 -B controller.py --execute --phase timing --source SOURCE_SHA256 --reviewed-build BUILD_TERMINAL_SHA256 --reviewed-parity PARITY_TERMINAL_SHA256
```

Run from the MadGraph repository root using this proposal's full controller
path. `prepare.py` and the pure tests read/hash files only; they perform no
compiler, loader or native worker calls. Source preparation history retains the
initial unexecuted input snapshot and explicitly records the absence/shell
infrastructure corrections made before any native work.
