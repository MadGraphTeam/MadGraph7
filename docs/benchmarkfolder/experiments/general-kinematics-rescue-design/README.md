# General kinematics and rescue: source-only requirements

This audit identifies a bounded route from the retained QCD/EW experiments to a generated implementation. It changes no production code, exported process, parameter, threshold, library, campaign identity or acceptance criterion. No compiler or numerical routine was executed for this package. The proposed behavior is not qualified physics or performance.

The immediate scope is the existing scalar optimized SM QCD/EW exports, ordinary on-shell external legs, crossing, and real/CMS internal masses. Preserve existing reducer capabilities and fallback chains; this proposal does not require every reducer to acquire a new QP API. Off-shell/spacelike repair, vector lanes and broader model support remain separate extensions, not additional gates on the present task. Unsupported new classifications must retain an explicit compatibility/fallback path.

## What is established, and what remains a risk

* **Recorded input discrepancy:** the retained QCD trace identifies 19 composite channels per direction that the historical matrix builder set to zero. The topology experiment gated those assignments; fewer refusals or a checked host return did not by themselves establish accurate amplitudes. The independent double-pole check is only one normalization check, not finite/single-pole truth.
* **Recorded representation differences:** the private Born B control used exact promotion of the original DP point while the loop used repaired C. The C variant aligned coordinates, retaining the intentionally different promoted-DP Born versus existing-MP loop parameter policy. The mass audit also observes DP-square-then-promotion versus squaring an existing MP mass. These observations do not establish which difference causes a remaining refusal.
* **Source-visible generalization gap:** the ordinary host publishes Born on `P_USER` before later QP repair, even if that Born is finite. A fallback limited to nonfinite Born cannot establish general Born/loop coordinate consistency. The source ordering is established; an inaccurate amplitude for every finite-Born point is not claimed.

Exact evidence files and inspected source bytes are pinned in `source-bindings.json`. The private QCD prototype used one generated process and retained its parameter limitation; the EW mass prototype uses explicitly selected backends 8/9. Neither is a general exporter implementation or an all-reducer qualification.

## 1. Generate identities with the reduction calls

`HelasWavefunction.get_struct_external_leg_ids()` returns unsigned sets of outer non-loop leg numbers (`core/helas_objects.py:2403`). `LoopHelasAmplitude.get_denominators()` walks ordered loop corners, despite its shift-like docstring (`loop_helas_objects.py:401`). `set_mothers_and_pairing()` fixes the actual mother/corner grouping (:366). Derive signed integer incidence from this graph and the HELAS momentum convention, then independently validate it against emitted mother/PAIRING order. Do not use numerical vector matching, source-text parsing, or fermion-flow signs as a substitute for the physical momentum convention.

Bind the resulting table after group sorting/renumbering (:649–694), and verify every grouped amplitude. Bind actual reduction IDs, not a presumed enumeration of `loop_groups`: ungrouped/loop-induced calls use distinct paths (`helas_call_writers.py:1905–1909,1961–1984`); color-flow output disables grouping (`loop_exporters.py:2277`). Preserve existing grouping keys and call ordering.

Apply the adapter's literal shift construction symbolically. Retain the closure shift, rather than silently replacing the sum of corners by zero. CT2/CT5 with N>2 reverse and negate corners and permute masses; N<=2 is unchanged (`TIR_interface.inc:359,413`). For each pair retain direct single leg, conservation-complement with its integer witness, composite, closure-only or unknown. A complement identity assumes momentum conservation; it does not prove exact closure of finite-precision input.

Emit a compact static pair-class/external-leg table with explicit group and direction arguments. Full incidence vectors can remain an export audit artifact. Standalone diagnostic calls without metadata must not inherit a previous COMMON group ID. In the new classified path, unknown/composite distances remain computed distances, without a smallness-based shell assignment; unavailable routing uses a documented legacy entrypoint or ordinary backend fallback. Do not label that fallback topology-certified.

## 2. Choose the shell and mass representation explicitly

Classification applies to `D_ij=(q_i-q_j)^2` before `S_ij=D_ij-M_i^2-M_j^2`. A certified external-leg identity selects that leg's declared real shell target, conditional on the chosen on-shell input policy. It does not select an adjacent internal mass. Current common builders test internal masses (`CT_interface.inc:163,235`); COLLIER has separate cyclic invariants, all-mass tests and an internal-stability cache branch (`COLLIER_interface.inc:229–311`). Supply a verified map for each actual convention. Inventory common-helper users, COLLIER and shift-based APIs separately; no single-helper edit covers every reducer.

For internal masses, reuse the symbol already selected by `get_masses()` (`loop_helas_objects.py:421`) and resolve its declared MP counterpart. Examples are real `MDL_M`/`MP__MDL_M` and complex `CMASS_MDL_M`/`MP__CMASS_MDL_M`. Square the existing MP value in QP, retain the complex width, and do not reinterpret card decimals or project a complex pole onto a real external shell. Derived MP parameters may differ before squaring. Keep the original DP and legacy interfaces and their arithmetic ordering; the separate paired-mass prototype is an implementation candidate, not proof of coverage.

Use the established model initialization contract. The retained model's `MP_UPDATE_AS_PARAM` refreshes MU_R/AS/G-related state, not arbitrary changed masses/widths; full model reinitialization must invalidate dependent caches. Retain each reducer's existing scale convention while isolating the mass change. A wider scale-policy change needs separate evidence.

The process `offshell` flag is distinct from `onshell` (`base_objects.py:2850`). Current repair generation parses `*` and emits `SQRT(ABS(p^2))` (`loop_exporters.py:1376–1405`); its passed KEEP_OFFSHELL_MASS array is not the branch selecting that formula. This does not establish preservation of signed spacelike virtuality. Keep such cases explicitly outside the new on-shell policy until their contract is designed; do not force a real/CMS shell onto them.

## 3. Own one effective point and parameter state per rescue

The optimized host publishes Born and REF before resetting MP state (`loop_matrix_standalone.inc:803–851`), then lazily prepares C (:1054–1056). For any adopted C-based rescue, including a finite DP Born followed by loop rescue, make the published Born, interference Born, UV/IR normalization and reference comparison follow one declared coordinate/parameter prescription. Preserve ordinary successful DP behavior. Comparing C with an independent calculation means sharing C and the parameter prescription, not claiming unchanged-original-point equivalence.

Initialize the model first and synchronize required MP scale/couplings before a genuine QP Born calculation. Generate/reuse the proper Born aggregation, including split orders, helicity/polarization/flavor selection, color factors and averages; do not generalize the private fixture's hard-coded aggregate. The existing MP integrand flag controls real QP evaluation versus DP computation followed by promotion (`mp_compute_loop_coefs.inc:209,371–399`); record and respect that distinction.

Prepare C once per current rescue. Adopt it after normal resets, or hand it explicitly through them; avoid a second DP or MP repair. Derive any rounded DP trial once, retain full C as the fixed MP point, and rotate from it. Coordinate readiness is separate from numerator completion and checked-amplitude acceptance. Invalidate relevant caches on effective-point, parameter or policy changes, preserving independent primary/check evaluations and existing lifecycle rules. Reset current-call certificates on entry and all failure exits.

`SET_MP_PS` returns no success flag (:2367), and `improve_ps.inc:89–147` may keep its input after failed repair. A finite returned point alone is therefore not a repair certificate. Carry an explicit outcome for the new internal rescue path and refuse unsupported/nonfinite/conversion-failed results through existing host failure semantics. An extra public API is not required. Preserve caller traps, rounding, entry flags, accumulated errors and filter-learning behavior; preparation must not manufacture checked status.

Loop-induced exports keep Born zero and use history-based REF (:803–841,1602–1632); they need a distinct branch, not a Born-rescue trigger or division by Born. Color-flow paths can replace the separately published Born (:1021–1027,1103–1107). Preserve those aggregation contracts if those existing export modes are included; otherwise declare the new path unavailable there without changing their legacy behavior.

## Bounded implementation and validation order

1. **Exporter/source proof:** emit graph metadata and paired MP mass routing in a private export; verify grouped/ungrouped IDs, SM crossing, N=1/2 boundaries, both directions, real/derived/CMS declarations and legacy signatures. Reproduce the retained QCD literal pair identities without a production source parser. Exercise existing loop-induced/color-flow modes only where the new path claims support.
2. **Input and lifecycle proof:** test direct/complement versus tiny composite channels and closure residuals; verify exact same effective C and parameter inputs for each supported reducer. Include fresh initialization, finite-but-unreliable/nonfinite Born cases, repair/conversion refusal, ordinary–stress–ordinary sequencing, rotations, mixed backend chains, real/promoted QP integrands, model reinit, pole/finite modes and cache reuse. Preserve IEEE behavior and failures; a refused case is not a numerical pass.
3. **Physics and performance:** require independently checked full amplitudes at a shared effective-input prescription for the existing supported SM QCD/EW benchmark processes and relevant CMS cases, retaining pole-only/finite limits and status evidence. Preserve the campaign's accuracy and runtime criteria. Measure ordinary-path overhead only after correctness; static lookup and rare-path preparation are design intentions, not measured speed claims.

Broader off-shell/spacelike support, vector lanes and additional public interfaces are follow-up scope. They are not prerequisites for qualifying a correctly bounded SM on-shell implementation. This document grants no build/run authorization or production promotion.
