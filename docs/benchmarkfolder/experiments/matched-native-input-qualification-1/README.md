# Matched native input qualification: one ordinary control and CMS point 20

The two private QP paths agreed at CMS point 20 after their native inputs were made identical and recorded. The maximum relative difference across Born, finite, single-pole and double-pole outputs, including split orders 0 and 1, was **2.01363060398197313 × 10⁻¹⁶**. This is agreement between two precisely bounded private paths. It does not establish independent physical accuracy or qualify a production change.

The closed run contains four outer calls, four initialized READY/DONE map captures and 104 native calls: 26 groups per phase and backend. For backend 8 the numerator is passed to NinjaRS; for backend 9 the captured canonical numerator is the Fortran contraction buffer, not an argument to the tensor API. Input finiteness, complete capture, caller environment, precision route, native status, finite native results, outer return validity and both bootstrap controls passed before measurement coefficients were compared. The saved comparison is reproduced byte for byte by the portable verifier.

The private backend-8 path explicitly aligns the promote-`MU_R`-then-square scale policy with backend 9 and uses the same certified raw/direct spacelike invariant choice. Each backend recorded ten selected direct matrix entries across groups 3, 4, 8, 12 and 24. The loaded TIRust provider is the existing `eb3d67fd…` library; no alternative library was built for this experiment.

```sh

python3 -B docs/benchmarkfolder/experiments/matched-native-input-qualification-1/verify.py
```

The verifier also works with a standard Python installation after moving these three public directories together. It reads only their indexed text, authenticates both sibling inventories, replays the retained scientific decoder and gated comparator, verifies the closed build joins, and reproduces raw output-word parity. It does not execute retained controllers, compile code, invoke loaders, read external binaries or launch amplitudes. `capture.py` records how the original text was copied from explicit immutable source and closed stage lists; it is not a portable runtime command. Compressed files are deterministic gzip copies; indices preserve their original byte counts and SHA-256 identities. No native binaries are included.

`build_checks.py` rederives twelve selected products, 26 call routes and preserved routines from retained source text. The historical full source inventory is not freshly materialized. Four materialized source pins are joined to retained bytes; the polynomial source pin is joined to its historical build inventory only. `worker_checks.py` uses the original scientific decoder and comparator logic with retained-byte access replacing filesystem access. Worker protocol events are retained in their closed result receipts; a separate raw FIFO transcript was not saved. Its historical preflight metadata remains qualified as historical; the original preflight's null `sealed_index` is not rewritten. No new compiler, materialized-source or runtime-provider preflight is implied.
