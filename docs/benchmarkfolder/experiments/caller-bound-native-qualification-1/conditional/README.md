# Conditional caller-bound calculation on retained CMS inputs

This is a pure, exact-arithmetic investigation, not a native or amplitude test. It authenticates the published runtime capsule 730f8f22, its two terminal closures, and six closure-bound trace streams, then uses the unchanged aba90345 caller factory and 1665eff3 certificate reference.

Each stream contains groups 3, 4, 8, 12 and 24. All 30 captured calls and 360 ordered off-diagonal pairs are included. Actual external W real/imaginary words feed the factory; actual matrix chord words feed finish_difference_bounds. Rounded differences, products and sequential subtractions are reconstructed with exact rational nearest-even binary64/binary128 arithmetic; every captured real DIFFSQ matches, and every imaginary DIFFSQ is zero. This supports this conditional arithmetic calculation but does not prove the future caller's environment token or genuine-QP producer contract.

Results: 240 protected pairs, 120 composite pairs; 60 conditional spacelike certificates, including 40 pairs on which the original zero branch was taken. No protected pair receives a certificate. The four previously causal group3 pair(2,4) stress cases are admitted (and their transposes are included):

|---|---|---|---|
|20|DP1|-22|-62|
|20|QP4|-22|-122|
|21|DP1|-36|-67|
|21|QP4|-36|-136|

Ordinary point1 pair(2,4) is also resolved spacelike but does not take the original zero branch, so it requests no invariant change. For stress points, all five captured groups have the same conditional pair(2,4)/(4,2) eligibility. The packet contains no event-specific certificate rule; each row uses the same immutable source DAG and actual runtime words.

Assumptions remain explicit: the new fresh entry/use environment contract is valid throughout construction, the QP W producer is genuinely same-kind QP, source/compiler arithmetic obeys the audited contract, and the actual route metadata is passed by the valid amplitude caller. Old traces do not observe the new tokens or prove the producer contract. ENV=false or missing producer proof requires legacy fallback in the future implementation. The old native failures do not invalidate captured input words, and no failed output buffer, coefficient or physical accuracy inference is used here. No shell threshold, source, card, scalar mass contract, runtime or published evidence was changed.
