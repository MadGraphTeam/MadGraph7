# Final fixed native Float256 request screening

Root authorized this bounded study before its timer helper is compiled. The
existing interpreted, denominator-only and full-native policies remain the
only three arms. This is the last proposed native experiment; it adds no new
optimization, precision setting, master provider, threshold or production API.

The original prepared source, recovered binary and four completed correctness
stages remain immutable. A separate private source copy adds a supplemental
ignored retained-state error/late-entry test and this ignored screening helper.
The original archive/source/binary hashes must remain unchanged after relink.
The ordinary suite and the new focused control must pass on the new binary.
The fixed screening input is the original ordered1392-request capture bound in
`prepared.json`; expected statuses and all11136ASCII fields per policy come
from the completed first replay, with no rewritten historical expectations.

The measured scope is one complete private `MpState::evaluate` call for each
of all1392requests, in order: recover113-bit input records, widen to256bits,
reset/set tensor input, rebuild numerical reduction inputs, evaluate reduction
and scalar masters, and format eight output ASCII fields. Each policy owns an
independent reused state and topology/rank cache. Inputs and request channel
objects are prepared outside the timer. Warm every complete stream once for
each policy before sampling, then retain each state through the fixed series.
Reserve the result-vector capacity before the timer; returned output-buffer
allocation and its push remain inside, serialization and output-buffer release
outside. The tiny catch-unwind boundary is common to all arms. No-op or
initialization cost is subtracted.

This scope excludes MadLoop's Fortran numerator and kinematics construction,
stability controller, and the public MP manager's channel round trip. It is a
request screening benchmark, never full-MadLoop performance, an original-Ninja
comparison, or proof of the final5% per-process gate.
