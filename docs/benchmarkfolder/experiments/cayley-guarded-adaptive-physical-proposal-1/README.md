# Frozen source-only guarded adaptive physical replay proposal

This packet preserves the first physical replay proposal for the private
Cayley zero-denominator guard. It remains **unexecuted and unbound**. Its
target is build proposal2, source index
`85e950b7d431988beb2481eeb2ad88ff4c0db3494121fcc986f9821ae3e9fd21`.
That build reached its 600-second limit without producing a qualified shared
library. No library hash is assumed, and this packet must not be retargeted
to a later build. A later proposal requires a separate additive source freeze
and root review before any binding or execution.

The existing controller, assessment, prepared specification, fixtures and
driver witness are preserved unchanged. No compiler, linker, loader, native
worker or numerical lock has been run for this proposal. Source verification
reads and hashes existing native artifacts; it does not load them.

## Proposed experiment and existing evidence

The controller reuses the already built checked diagnostic executable
`0181fba617011c58b36cc8d59bbc92d807f670f19f3d74ea64dc8539b11c8e28`
and all 25 numerical objects unchanged. The driver witness records the same
bootstrap, alternating two-point warmup and consecutive T1/T2 readiness
protocol. Readiness identifies finished initialization and is never physics
acceptance.

Four fresh guarded-library workers were proposed: checked masked/trapped
with `CTModeRun=-1`, `NRotations_QP=1`, and forced-QP masked/trapped with
`CTModeRun=4`, `NRotations_QP=0`. Each card is byte-identical to its corresponding
closed comparator. The physical inputs, genuine binary128 mass/numerator
path, backend9 selection, thresholds and other controls remain fixed.
Three deliberate invalid/divide-by-zero/overflow fault controls and one
runtime-loader listing were also proposed. Existing original/adaptive
comparators are reused as frozen text; they are not rerun.

The inherited process supervisor enforces the common nonblocking numerical
lock, CPU12 without reservation, 4GiB address space, 120 seconds per physical
worker, 10 seconds per fault/loader worker and one 600-second aggregate
deadline. Actual 15-library mappings, reaping, input closure and output closure
are required. There is one attempt and no automatic retry. No such attempt
has been created here.

## Qualification gates

The existing checked journal parser, named IEEE parser and checked-output
qualifier are reused unchanged. Checked acceptance requires independent
MadLoop checks, observed QP coverage, complete sums and zero W03 omissions.
The source journal identifies complete `[4,5,4]` traversals but does not
explicitly label the rotation or report each call's working precision.

The separate fixed-QP qualifier requires unchecked status120, exact accuracy
sentinels `[-1,-1]`, one 200-group mode4 traversal and one genuine-QP model
snapshot per point. Every group must be served and stable with backend9,
check-pass false and caching enabled; raw tensors, contracted results and
amplitudes must be finite. W03 diagnostics reject contribution completeness.
Status120 never establishes numerical stability.

Both policy workers must preserve physical inputs, Born values and outputs
exactly where required. The frozen c5de checked and fixed outputs must remain
exact; all previously served original checked results must also remain
exact. Named hardware observations and inherited software failure latches
stay separate from physical input comparisons. Both qualification gates
require successful trap controls, complete transport and final protected-input
closure; deadline or closure failure clears them.

Independent physical truth, per-call 256/512-bit provenance and performance
remain unqualified. This is the old private genuine-MP-mass diagnostic,
separate from `invariant-symmetry-1` and production. No installation prefix or
COLLIER code/cache behavior is changed.
