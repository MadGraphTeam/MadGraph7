Run from any directory with Python 3.10 or newer:

```text
python3 -B /path/to/preflight-fixture-evidence/verify.py
```

`verify.py` verifies the complete file inventory (including extra-file rejection), all payload hashes and the fixed historical failure hashes. It imports only the exact frozen `fixture/validate.py`, maps its `ROOT` and `HERE` to the packaged payload, and calls its unchanged `validate()` with the preserved corrected event record. Historical absolute argv strings remain unchanged for exact event comparison. The result must equal the retained offline PASS in full, including all journal hashes. The verifier also reproduces the original stale-path rejection and rejects any amplitude-worker event in these captured runs. It launches no subprocess and needs no compiled artifact. `index.json` binds all package files except itself; its hash is supplied separately with delivery.

`prepare.py` documents the explicit text snapshot selection. It is a repository-local preparation utility, not a portable rebuild command. `freeze.py` creates the final closed inventory once; it must not be rerun to conceal changes. Source preparation made no production, installed-library, reference-repository or frozen-source edits. No native process was launched while preparing or verifying this package.
