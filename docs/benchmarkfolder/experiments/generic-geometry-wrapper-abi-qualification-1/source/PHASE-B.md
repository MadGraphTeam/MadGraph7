# Deferred phase B: actual SLOOPMATRIX lifetime paths

Phase A is an exact emitted provenance-wrapper/module ABI fixture. Its direct
FRESH=false inputs do not execute SKIP_LOOPNUM, MP_DONE, FILTER_SO, rotations,
or MP-to-DP narrowing in SLOOPMATRIX. No phase-A outcome may close those gates.
The pure source-generation fixture has NSQUAREDSO=0 and is not a complete CLI
standalone amplitude. It cannot be upgraded into full-caller qualification by
renaming a case or supplying synthetic freshness arguments.

A bounded full-caller successor needs the following explicit preparation:

1. Materialize a complete private production-source0fcd/exporter-afb6 checkout,
   then apply the exact source1, source2 and source3 overlays in order. Keep the
   canonical installed eb3d TIRust DSO and all reference repositories unchanged.
   Enable the private `invariant_provenance` exporter option in a pinned CLI
   bootstrap (for example the optimized exporter's private default_opt mapping),
   rather than modifying a public option/default or treating the pure fixture
   as an executable export.
2. Generate actual CLI standalone exports for a small Born SM control and the
   pinned complex-mass Gmu fixture. Freeze complete model/card/point/source/route
   inventories, actual generated split orders and dimensions; require a valid
   nonzero physical NSQUAREDSO before building. A loop-induced export can observe
   skip behavior while retaining its unknown source-window admission false.
3. Build an uninstrumented pass-through export and an observational derivative
   with identical compiler, cards, model and numerical libraries. Keep scientific
   dispatch legacy. The derivative should record entry/use tokens, CTMODE,
   width, source-bound slot words, GP_FRESH, and actual execution markers placed
   immediately after the exact DAG-receipt producer calls. It must not infer
   execution merely from a call appearing in source or a flag being assigned.
   Bind each insertion to the actual statement span/continuations and common
   prefix; no floating arithmetic or source-allowlist replacement belongs there.
4. Use the existing actual worker/cleanup/runtime capture machinery. Preserve
   normal learning and stability policy for amplitude comparisons. First bound
   ordinary DP and genuine automatic QP paths; then exercise real rotations,
   split-order FILTER_SO requests, skipped/coefficient-reuse paths, MP_DONE reuse,
   the explicit widened-DP QP option, and observed MP-to-DP W storage narrowing.
   Branches must be reached through their actual generated callers/public
   controls and measured. A branch not reached remains unqualified; manually
   passing false freshness to phase A cannot substitute.
5. For an admitted use, require every necessary same-kind W.P producer marker
   in the current pass, a fresh admissible matching token, unchanged relevant
   source-bound slots, exact route/width and complete integer bounds. A negative
   path must expose unavailable bounds. Compare all amplitude/status/accuracy
   words and observed flags against the uninstrumented legacy pass-through
   export, preserving any existing scientific refusal as a refusal.

Generation, full builds, and runtime each need separately reviewed fixed input
and command caps. A proposed initial envelope is one small export at a time,
120 seconds generation, 180 seconds full build, then a 300-second checked worker
stage including cleanup reserve under the shared numerical mutex. These are
unexecuted planning bounds, not a native admission or a performance result.

Only after actual lifetime/ABI coverage can a separate private scientific
dispatch join the previously tested integer-certificate correction. That later
stage must retain supported/unknown routing, normal checked DP-to-QP rescue,
cache0/-1 comparisons, complete Laurent results, matched-input/analytic pole
evidence and unresolved independent finite truth. Production promotion and
Hua-Sheng's precise local performance campaign remain later requirements.
