## Portable verification

From any directory, using a Python standard-library environment:

```sh
python3 -B /path/to/generic-invariant-provenance-source-1/verify.py
```

The wrapper authenticates the public payloads and exact original index, replays the original patch/template/table verifier, and reruns all **17 sealed pure protocol tests**. For the test run it provides in-memory `madgraph` package facades containing only authenticated source definitions. It does not import a workspace checkout or alter the retained tests. During replay, writes, external processes, foreign-library loads and reads outside the packet/Python environment are blocked. Historical absolute paths in receipts remain inert text.

An optional explicit repository check is read-only:

```sh
python3 -B /path/to/generic-invariant-provenance-source-1/verify.py --repo-root /path/to/madgraph7_madloop_tirust
```

This checks the original production-file pins. It does not run MG generation, compilation or numerical work. The original `source/verify.py --live` assumes its historical directory layout; use the public wrapper for optional repository checks.

Copy the entire `source/` directory to a fresh child of that repository's `.tirust-build/` directory, then run its `test_protocol.py` and `test_generation.py` using `python3 -B` from the repository root. The generation test writes only inside that fresh copy and blocks subprocess/native launches. Do not run it in this published packet or over an existing sealed source directory.

They establish source generation and geometry-table behavior; they do not qualify full model closure, compiler integration, ordinary checked rescue, native floating-point state, numerical accuracy, performance or a general scientific correction.
