ChannelEventGenerator¶

class ChannelEventGenerator¶

Event generation and integration for one integration channel.

Owns one channel’s compiled integrand, unweighter and (optional) histogram runtimes, one set per Context passed to the constructor, and runs its survey, VEGAS/channel-weight optimization and unweighting. EventGenerator coordinates one ChannelEventGenerator per channel of a subprocess.

Public Functions

ChannelEventGenerator(const std::vector<ContextPtr> &contexts, const Integrand &integrand, const std::string &event_file, const std::string &weight_file, const GeneratorConfig &config, std::size_t subprocess_index, const std::string &name, const std::optional<ObservableHistograms> &histograms)¶
Parameters:

  • contexts – One context per device to run on.

  • integrand – The channel’s compiled integrand.

  • event_file – Path of the event file; empty for no file.

  • weight_file – Path of the file with the per-event weights, which unweight_file unweights in place; empty for no file.

  • config – Generator configuration.

  • subprocess_index – Index of the owning subprocess.

  • name – Human-readable channel name.

  • histograms – Optional observable histograms filled alongside integration.

double abs_integral_estimate(bool final_step = true) const¶

The integral of the absolute weights: the mean of this run, combined with the prior (if any) weighted by the inverse variances.

Used to share the events between channels. With final_step, the integral after the weighting steps, see result_integral, otherwise of the first step.

double count_after_target(std::size_t target_count) const¶

The unweighted event count set_target_count with target_count would leave: a smaller target can raise the maximum weight, which accepts proportionally fewer events.

Apply the truncation budget of the current target count to the maxima of the steps, which are updated with the target count of each job.

Dispatch job (a survey or generation batch) onto the thread pool, seeded from seed.

void prepare_unweight_job(GeneratorBatchJob &job) const¶

Snapshot max_weight into job.max_weight, at a fixed point independent of when submit_unweight_job actually dispatches it.

std::size_t next_vegas_batch_size()¶

Size of the next VEGAS/channel-weight optimization batch.

Discard the accumulated events and weights, and reset the integral, the event counts and (unless fixed) the maximum weight.

Update max_weight from a batch of weights, which are unweighted later if unweight is true.

Pack unweighted_events into event_buffer (layout event_file_layout) and their weights into weight_buffer (layout weight_file_layout), resizing both.

void save(const std::string &file_name) const¶

Serialize this generator’s state to file_name; see load.

std::string to_json(bool include_estimates = false) const¶

The JSON text that save writes; see load_json.

With include_estimates, the current maximum weight and, if there are at least two samples, the integrals (signed and absolute) are stored as well. load_json then keeps the maximum weight fixed and uses the integrals as priors, see abs_integral_estimate.
