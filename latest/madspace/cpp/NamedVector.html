NamedVector¶

template<typename T>
class NamedVector¶

Ordered, name-indexed vector: a std::vector<T> where every entry also has a unique string key.

The container behind every compute-graph Function’s named inputs and outputs (NamedVector<Value>) and type lists (NamedVector<Type>), preserving insertion order while supporting both integer indexing and lookup by name.
