FunctionBuilder¶

class madspace.FunctionBuilder(self: madspace._madspace_py.FunctionBuilder, input_types: madspace._madspace_py.NamedTypes, output_types: madspace._madspace_py.NamedTypes)¶

Bases: pybind11_object

Records instructions and freezes them into a Function.

Construct it with the input and output types, read the graph inputs with input, add nodes by calling the instruction methods (for example add, stack or two_body_decay_com, listed below), wire the results to the outputs with output, then call function to obtain the finished Function. The instruction methods are generated from madspace/instruction_set.yaml.

Start an empty builder with the given input and output types.
